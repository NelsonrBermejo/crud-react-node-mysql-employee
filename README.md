# Employee CRUD

A CRUD application built with React, Node.js, Express, and MySQL.

## Getting Started

### Frontend

1. Navigate to the client folder:

   `cd client`

2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm start`
